Now Playing

Maps to now_playing_screen.dart and now_playing_controls.dart. The full transport cluster: play/pause, ±15 s, previous/next chapter, speed 0.5×–2×, sleep timer and bookmark.

1. Transport cluster

Departures from today. (a) The current cluster wraps everything in a FittedBox(scaleDown), so on a phone the whole row — including the 80px play button — shrinks together until nothing meets a 44px target. Here the cluster wraps onto a second line instead of shrinking. (b) The skip buttons are labelled ±15 s but draw Icons.replay_10_rounded / Icons.forward_10_rounded, so the icon says 10 and the code does 15. The number is now rendered from the same value that drives the seek, and it is user-configurable. (c) The speed and sleep-timer chips are 11px bold text inside a PopupMenuButton with no accessible name. They become labelled selectors with a visible current value, plus an expanded speed row for direct selection. (d) The play button drops its 24px coloured bloom shadow — a leftover of the rejected neon pass — for a plain elevation-2 shadow.

4. Accessibility contract

  • Every transport control has an explicit label. The skip labels contain the real interval and re-read correctly if the user changes it from 15 s.
  • Speed and sleep timer are radiogroups with the current value in the trigger's accessible name — a user never has to open the menu to learn the current speed.
  • The remaining-time figure is the one users act on, so it is shown as a signed value (−16:37) alongside elapsed, and both are tabular.
  • Keyboard: space toggles play, left/right seek ±15 s, up/down change speed one step, [ and ] change chapter, b adds a bookmark.
  • Nothing in this screen is hover-only. Every control is present and hit-testable on touch.
