Book row & shelf tile

The two ways a book appears in a list: the library row (library_view.dart) and the discover tile (librivox_book_item.dart). Both carry a preview only variant that the canned web demo needs, so a visitor can never mistake an unplayable catalogue entry for a working one.

1. Book row — library list

Departure from today. The current row is a ListTile inside a GlassCard with a 14px bold title, a 12px subtitle at alpha: 0.6 (4.29:1 — fails AA), a generic Icons.book_rounded instead of the cover, and no progress indicator even though progress is stored. Here: real cover, 17px title, 16px secondary at 7.70:1, resume progress, and status badges.

Departure from today. The current tile is 110×145 with a 10px title and a 9px author at alpha: 0.5. That is unreadable for the stated audience. The tile grows to 148px so the title can sit at 16px and the author at the 13px floor. 3. Accessibility contract

  • A row or tile is one semantic node: Semantics(button: true, label: "Moby Dick, by Herman Melville, 42 percent complete, chapter 57"). Today each is a bare InkWell with no label, so VoiceOver reads only the visible fragments.
  • The preview-only state is announced, not merely styled: the badge text is part of the label and the play control is Semantics(enabled: false) with a reason.
  • The procedural cover is decorative — ExcludeSemantics. A real cover image gets the book title as its alt text.
  • Selection uses aria-current / Semantics(selected: true), and is signalled by an outline plus a badge, never by colour alone.
